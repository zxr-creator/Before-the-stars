Before the Stars
================

Run "Before the Stars.exe". A console window opens (keep it open while you
play) and the game appears in your web browser at http://127.0.0.1:7878.
To stop the game, close the console window or choose "Quit game" in the
game's menu.

Windows SmartScreen may warn about an unrecognised app because this build is
not code-signed: choose "More info", then "Run anyway".

Saves are kept in %APPDATA%\Before the Stars\saves.

AI opponents that use Claude or Codex need their own accounts:
  - Claude (API): set the ANTHROPIC_API_KEY environment variable, or type a
    key when creating a match.
  - Claude Code / Codex: install and log in to those command-line tools.
The built-in Easy/Medium/Hard opponents need nothing.
