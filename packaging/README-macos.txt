Before the Stars
================

Install: drag "Before the Stars" into Applications, then open it. The game
opens in its own window. Control-Command-F (or the View menu) switches full
screen; Command-Q quits and saves.

First launch: this build is not signed with an Apple Developer ID, so macOS
will refuse a plain double-click. Right-click (or Control-click) the app,
choose Open, then Open again. You only need to do this once.

Saves are kept in ~/Library/Application Support/Before the Stars/saves.

AI opponents that use Claude or Codex need their own accounts:
  - Claude (API): set ANTHROPIC_API_KEY, or type a key when creating a match.
  - Claude Code / Codex: install and log in to those command-line tools.
The built-in Easy/Medium/Hard opponents need nothing.
