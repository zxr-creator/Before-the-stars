## Results and evidence limits

Baseline industrial acceptance occurred at E month 48, S month 60 and D month 72. Project cash at month 120 was respectively 27,500, 23,376 and 18,412 c. These were paper results under specified suppliers, orders, talent and capital, not whole-game win rates or FTL victory times.

With the same inadequate-hydropower shock, fixed E completion moved to month 84. A real contracted equipment lease completed at month 54: 30 months sooner than waiting, with 424.50 c less retained at month 120. A decision can therefore create a large time advantage. No automatic label bonus follows, and the analysis did not search all mixed schedules.

The release checked dependencies/links, local recipes/training, independent 120-month cash/output arithmetic, shock/lease cash and paper exploit cases. Raw-material upstreams, complete civil works/equipment, all technology recipes, batch copper transport, endogenous markets and population behavior were not fully frozen. Document checks were not runtime exploit tests or proof of no vulnerabilities.

## Package boundaries

- Root README and docs preserve relative paths for reading or placement in a GitHub project.
- `MANIFEST.SHA256` lists source-file digests, excluding itself; it is not a provenance signature. The external `.zip.sha256` checks the whole archive.
- No `.git`, local tool configuration, credentials, caches or nested archives are included.
- JSON under contracts is historical; read its README. It is not the v0.7 executable interface.
- This is omniscient designer material containing latent graphs, endgame and hidden mechanisms. Seats need scoped observation projections. A public repository cannot erase a model's prior knowledge; isolation protects actual match secrets and unauthorized access.

Prices, efficiencies, courses and slow-variable values remain candidate content. Excellent strategies may achieve large leads and wins. Only violations of ledgers, authority, timing or reward definitions require exploit repair.
