## What changed

All active README, design, technical, review, reference, roadmap, contract and release documents are in English. Human-readable content in the two historical JSON examples has also been translated; their IDs, numeric values and old protocol meaning remain unchanged. The other five historical JSON files remain structurally unchanged. Earlier ZIP releases are preserved as immutable historical artifacts; this v1.0 ZIP packages the translated current working documentation.

The full content remains 138 technologies, 64 practices, 24 courses, 34 recipes, 10 capital modules, six transitions, eighteen tradition layers and nine advanced application packages. Corrected current prerequisite references total 403 for technology and 174 for culture. Fixed full graphs do not imply identical visible development or affordable execution in every world.

All official play is competitive with at most one winner. The standard world has four civilizations and 1–4 external human/agent seats; native non-LLM AI fills vacancies. The candidate shared clock is 12 months per round and H = 2,880 months. Real global authority plus sustained military FTL remains mandatory. Forfeiture cannot produce a caretaker victory; month-H completion is checked before timeout. Existing-charter voting now has a bounded path through `set_policy` without inventing new action types or arbitrary free chat.

Population removes per-household marriage/parity, individual pregnancy/recovery, multipathogen compartments and monthly per-person job search. It preserves joint culture/religion/skill identity, compact annual ages, aggregate delayed births, access, health, shared labor, real courses and mobilization. Culture stays slow and private. Performance figures are representation estimates/targets, not measured speedups.

Art now targets an original stylized 3D strategy atlas with a complete flat-map tier. The chronicle follows Civilization's illustrated Historic Moments/Timeline, per the user's final correction. civ-atlas remains a geography reference. Timeline cards show real accomplishments/reversals and optionally their evidence; they do not create resources, rewards or hidden-state explanations.

## Checks and limitations

The release checks local document links, Markdown fences/tables, absence of untranslated Chinese prose, JSON parsing, preserved historical example identities/numbers, catalog IDs, prerequisite references/cycles and selected reachability/window arithmetic. The archive is checked for CRC errors, manifest digests and byte-for-byte equality with included source files. These are documentation, graph and arithmetic checks, not runtime game tests.

Current graphs retain valid references and are acyclic. Structural reachability of FTL under selected excluded optional branches is useful design evidence, not proof of resources, teachers, affordable production or success against opponents. Conditional industrial/endgame schedules remain explicitly bounded; the cooperative M336 case is not a competitive simulation result.

Next gates are complete content-parameter freeze, machine contracts, authoritative ledgers and deterministic multicore execution, then playable competitive campaigns and measured visual/AI performance. No implementation began in this release.

## Archive contents

The archive contains 65 Markdown documents, seven historical JSON schema/example files and `MANIFEST.SHA256`: 73 files in total. It preserves root README and docs relative paths. The manifest lists every included source file and excludes itself. The adjacent `.zip.sha256` checks the whole ZIP. Hashes establish byte consistency, not a source signature.

Exclude `.git`, local tool configuration, credentials, caches, `.DS_Store`, helper scripts and nested release archives. Preserve old release ZIPs outside this package. This package contains hidden designer mechanisms and the full eventual objective and must not be mounted into a competitive seat's environment. A public repository cannot remove prior model knowledge; formal evaluations must report that limitation honestly.
