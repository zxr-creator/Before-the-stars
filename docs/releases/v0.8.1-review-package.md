# Before the Stars v0.8.1 design review package

Historical release record translated for v1.0. This stage added diplomatic communication rules and synchronized documents, without game code, schema migration or simulation. Production, population, fixed graphs, military FTL and full completion continued from v0.8. Earlier ZIPs remained unchanged.

## Key rules

Free text permits deception, concealment, probing, bargaining, threats and alliances. The engine authenticates source and real registration, not statements' truth. Formal duties require immutable terms, legal signatures, actual reservations and registry arrival.

New offers, counters, signatures and evidence sharing consume quota. Fan-out counts each actual pair. Controlled models, companies and delegations share one seat allowance. Each envelope holds one formal operation, 2,000 Unicode scalars, eight clauses, eight existing references and 16 KiB total. No extra invitation broadcast, unlimited attachments or free alliance group chat.

Mutual-selection lists seal simultaneously, without switching to a fourth target after refusal. A public round/window rule allocates the final permit rather than network speed. Retry, reconnect, rename and later-round arrival give no extra uses. Unused quota does not carry forward.

Automatic performance and fixed lawful withdrawal, dispute, exit and liquidation cannot be blocked by refusing chat. Exemptions cannot carry new text, quotes or terms. Ongoing trading relationships and general treaty machinery are not limited to three lifetime partners. Multilateral versions can travel and collect signatures across rounds; an anchor cannot consent for members. v1.0 later limits the selectable match to four civilizations while retaining generic machinery.

A signature creates a counted counterpart envelope and a necessary fixed registry copy. Each route pays real cost/delay, sharing one asset reservation. Negotiation-locked assets cannot be reused in plan. Actual registry receipt counts toward formation; a chat receipt does not form the contract.

## Review and limits

Chapter 29 contains a ten-envelope example and quota, group, proxy, cross-round, protected-operation, five-party and routing counterexamples. Original checks covered text links, tables, historical JSON readability, action counts and bounded arithmetic over remaining quotas 0–10, window alternation and legal send combinations. Archive checks compared manifest, hashes and extracted bytes.

These were not implementation tests or diplomatic balance proof. Selection/windows/signatures affect early distant negotiation and alliance timing; later compare identical starts and model budgets. Normal trade, real actions and independent intermediaries still convey information. The design does not eliminate all in-world signaling.

## Package boundaries

Contents were root README, docs and `MANIFEST.SHA256`, including historical records and seven old JSON drafts. Exclusions: `.git`, local configuration, credentials, caches, `.DS_Store` and nested ZIPs. External `.zip.sha256` verifies the archive; a digest is not a provenance signature.

This is omniscient designer material. Formal seats receive restricted observations. Follow the [index](../README.md); old machine contracts are not directly usable for current matches.
